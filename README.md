### 🎮 What I'm building right now

**APASMARA** — a solo indie psychological survival horror game, built in Unreal Engine 5.

Indian occult folklore meets clinical mortuary work: embalm the dead, figure out which body the demon is actually riding, apply the right ritual, burn it before dawn — or before your own sanity gets there first. The whole thing runs on a two-part AI ("The Overmind" and "The Voice") that learns what scares *you specifically* over a playthrough, instead of firing the same scripted jumpscares at everyone.

Built ~90% in Blueprint, with C++ dropped in exactly where the math needs it — not because Blueprint can't do it, but because that's the honest split for a solo dev learning as they go.
